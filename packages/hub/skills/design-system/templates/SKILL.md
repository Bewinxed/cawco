# <Project> design system

Build in <project>'s look, from its system in `design/`:

1. Read `DESIGN.md` and `tokens.css` whole before you write any style.
2. Take every colour, size, space, radius, shadow, duration and curve from `tokens.css`'s custom properties, and build components to `DESIGN.md`'s recipes.
3. Open the rest as the work needs it: `manifest.json` for where a value came from, `fonts/` and `assets/` for the files, `specimens/index.html` to see the foundations drawn.

A value the system lacks is a change to the system: say which role it needs in your hand-in.
