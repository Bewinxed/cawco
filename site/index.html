One board for every coding agent you run.

Caw&Co is a self-hosted control plane for Claude Code, OpenCode and pi. A small daemon on each machine reports to a hub on your own network. One browser tab then shows you every session and lets you answer the ones that are waiting.

Install on your first machine

curl -fsSL https://cawco.dev/install.sh | sh

It's free and open source, and it runs on macOS and on Linux with systemd. Read the script first or browse the source.

See every session at once

The usual way
You keep one terminal tab per agent and one SSH session per machine, and you find out a session is stuck when you happen to look at it.
With Caw&Co
Every session on every machine is a row on one board. Caw&Co reads each status from the machine when you look, so a quiet board means nothing is waiting on you.

The usual way
You read each transcript to catch the same habits, like an agent saying a fix should work before running it, and you type the same reply again.
With Caw&Co

Let a session hand work to another

The usual way
You copy the task into a second terminal, wait, and paste the answer back.
With Caw&Co
A session can start a delegate: a separate session with the agent, model and effort you set for that kind of work. It reports back when it finishes. A workflow chains several steps and retries one that fails.

Set a tool up once

The usual way
You add the same MCP server, skill or hook on each machine by hand, and the machines drift apart.
With Caw&Co
Add it in the hub and every machine gets the same MCP servers, skills, plugins, memory and hooks.

Self-hosted

The hub runs on your tailnet or LAN and is never bound to a public address.
