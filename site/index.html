One board for every coding agent you run.

Caw&Co is a self-hosted control plane for Claude Code, OpenCode and pi. A small daemon on each machine reports to a hub on your own network. One browser tab then shows you every session and lets you answer the ones that are waiting.

Install on your first machine

curl -fsSL https://cawco.dev/install.sh | sh

Copying is blocked here. Select the command instead.

It's free and open source, and it runs on macOS and on Linux with systemd. Read the script first or browse the source.

Set a tool up once

The usual way
You add the same MCP server, skill or hook on each machine by hand, and they drift apart. One is a laptop you carry around half open so its agent stays awake.
With Caw&Co
Paste a skill's install command, an owner/repo slug or a GitHub, npm or https source, and every machine gets it. MCP servers, plugins, memory and hooks sync too. Long jobs can live on a machine that stays on, so the lid can close.

As fluid as your workflow will be

Lists reflow where they stand and trees fold open along their rails, so you keep your place while the work moves. Ask your system for less motion and the interface holds still.

Queue the next message

Send while the agent works. The message waits its turn, and you can take it back until it's read.

Long transcripts stay light

Only the rows on screen are drawn, and older history loads a page at a time.

Continue in a new session

The hub summarises a long conversation with a model you pick and opens a fresh session from it, on any agent or model.

Hand off, with a cost check

Sessions message each other across machines. When an agent sends follow-up work to a Claude Code session whose prompt cache has expired, the hub refuses the first try and says a fresh delegate is usually cheaper.

Self-hosted

The hub runs on your tailnet or LAN and is never bound to a public address.

Three agents, one board

Claude Code, OpenCode and pi run side by side.

Your own accounts

You sign in to each agent yourself. Caw&Co doesn't sell model usage.
