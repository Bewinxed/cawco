  Unmarked half — `checkDeploy` reads the marker BEFORE any git runs, so with a spy GitRunner

  runs at all — not even the fetch" asserts `state.kind === 'unmarked'` and `calls === []`;
  the poller test ticks a DeployWatcher twice over the unmarked clone and asserts `runs === []`
  and `calls === []`. A malformed or partial marker is treated as no marker (fails closed) —
  also asserted with zero git calls.
  Marked half — a real clone of the scratch bare origin with a marker: tick 1 on a level clone
  → `current`, 0 updates. `commit('second')` + push → tick → `behind`, `updated: true`, 1 run,
  and the clone's HEAD now equals origin/main. Four more ticks on the same head → still 1 run,
  state back to `current`. `commit('third')` → tick → 2nd run, with a different target sha.
  Dedup is by attempted target, so an update that THROWS is also not retried on the same head
  (asserted: 3 ticks, `attempts === 1`, failure surfaced through the report callback).
  No timer runs anywhere in the tests: `DeployWatcher.tick()` is called explicitly;
  `startDeployPoller` (setInterval, unref'd) is never invoked by a test.
