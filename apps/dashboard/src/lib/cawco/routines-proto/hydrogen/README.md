The Routines first view, trimmed by the `designing-first-views` skill from Gemini Hydrogen's bento (origin `cawco/80224d8f`).

1. One table of routines, a row each: its name over one plain sentence of what it last did or is waiting for, when it last ran, when it runs next on the person's clock, and a Needs you mark with a Fix with Caw button only when it stopped or its newest run failed. Those that need him lead, then the order they were made in, until he sorts by a column's head. Under a 640px table each row is one line: the routine, the mark when it needs him, and the open glyph.
2. Opening a routine (a press anywhere on its row) shows its latest run's whole result, what it does and when, what it waits for, and its earlier runs; Edit and Change with Caw sit at its head.
3. Opening a run shows its whole result and, where a session did it, the session.
4. The editor holds a name, what each run does, an optional "only run when", and the schedule.
