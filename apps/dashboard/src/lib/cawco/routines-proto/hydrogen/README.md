The Routines first view, trimmed by the `designing-first-views` skill from Gemini Hydrogen's bento (origin `cawco/80224d8f`).

1. One grid of routines, each shown once in a stable order: its name, one plain sentence of what it last did or is waiting for, and a Needs you mark with a Fix with Caw button only when it stopped or its newest run failed.
2. Opening a routine (its expand button) shows its latest run's whole result, what it does and when, what it waits for, and its earlier runs; Edit and Change with Caw sit at its head.
3. Opening a run shows its whole result and, where a session did it, the session.
4. The editor holds a name, what each run does, an optional "only run when", and the schedule.
