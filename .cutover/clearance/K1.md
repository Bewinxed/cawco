# K1: the table parts' variants

The recipes are `tv` in each part's `<script module>` (src/lib/components/ui/table/): `tableCellVariants`, `tableHeadVariants`, `tableRowVariants`, `tableVariants` (slots `container`, `table`). With no variant passed a part draws its base, as before.

A consumer site passes the props below and drops exactly the classes the appendix lists for it; every other class it passes stays on it. `bun .cutover/k1-exact.ts` proves each site equal to today, case by case (both branches of every conditional).

## Follow-up (the orchestrator's three asks)

### 1. Set 2's ledger rows

ProjectSpend's five `<Table.Row data-project-spend-row>` rows (500, 534, 588, 632, 658 on set 2's tree; the same five rows on 1a) carry set 2's `max-phone:border-b max-phone:border-b-border-hairline`. Their value, `variant="stacks"`, is used by those five rows only, so it draws both classes (table-row.svelte:14–15) beside `max-phone:gap-x-space-3 max-phone:gap-y-space-1 max-phone:px-space-3 max-phone:py-space-2`. `k1-exact.ts` adds the two classes to those sites' consumer classes today (`SPEND_ROW_ADDED`) and checks them in: 0 mismatches.

### 2. ViewRoutines.svelte:922 and :974: STOP

- **Part:** `<Table.Row>`.
- **Classes:** `band border-0`.
- **Conflicting rule:** `shadcn/no-unknown-classes` in the kit file.
- **Attempt:** a `ledger-band: "band border-0"` value in `tableRowVariants`, linted, then reverted. `bunx eslint src/lib/components/ui/table/table-row.svelte` gave:

  > `11:24  error  "band" is not a class this project's Tailwind knows, so no CSS is generated for it. Fix the spelling, or declare it with @utility in src/app.css. … shadcn/no-unknown-classes`
  >
  > `✖ 1 problem (1 error, 0 warnings)`

- **Why ViewRoutines may write `band` and the kit may not.** The rule (`@shadcn/lint` 0.2.1, `dist/index.js:5042`) admits a non-Tailwind class only if the same file's `<style>` declares it: `const ownClasses = isSfc(filename) ? styleClassesOf(context.sourceCode?.text ?? "") : new Set()`. ViewRoutines' `<style>` declares it (`[data-slot="ledger"] :global(tr.band)` and `tr.band th`, ViewRoutines.svelte:1149–1159). table-row.svelte has no `<style>`.
- **The ways to admit it are all outside K1, or a rule that draws nothing:**
  - `@utility band` in src/app.css;
  - an `allow` entry in eslint.config.mjs;
  - an empty `.band` rule in the kit file.
- **Proposal for set 4.** The hook's row rule paints `background: var(--surface-band)`, which is what `variant="band"` (`border-0 bg-surface-band`) draws. Once set 4 moves the `tr.band th` look onto the heads, those rows take `variant="band"` and the hook class goes.

### 3. Modern Tailwind and defensive CSS

`moderncss` and `tailwind-best-practices` were loaded. Truth is the repo's Tailwind 4.3.3, compiled through `src/app.css` with `@tailwindcss/node`. The docs page (https://tailwindcss.com/docs/hover-focus-and-other-states) was fetched with CRW, but the tool saved it outside this workspace's boundary, where it could not be read, so no line of it is quoted. The decisions below rest on the compile.

**v3-era patterns in the kit table files.**
- None of the listed ones occur: `bg-opacity-*`, `text-opacity-*`, `bg-gradient-to-*`, a leading `!`, `bg-[--x]`, v3 size names (`shadow-sm`, `rounded`, `blur`, `drop-shadow`), `@layer utilities`, `tailwind.config`.
- **Not fixed: `[&:has([role=checkbox])]:pr-0`** (table-cell.svelte:6, table-head.svelte:6). Its v4 form `has-[[role=checkbox]]:pr-0` doesn't compile identically.
  - The v3 form compiles to `.…:has([role=checkbox]) { padding-right: 0px }`.
  - The v4 form compiles to `.…:has(:is([role=checkbox])) { padding-right: 0px }`, a different selector at a different sort position in the utilities layer.
- No `v3 fixed:` lines.

**Defensive gaps** (recorded, not applied; each fix compiled in 4.3.3):
- `defensive: apps/dashboard/src/lib/components/ui/table/table-cell.svelte:6 3 (long words) a cell a consumer sets to wrap (whitespace-normal) holding user or agent text does not break long words or URLs; add wrap-break-word to the base (overflow-wrap: break-word; no effect while whitespace-nowrap holds)`
- `defensive: apps/dashboard/src/lib/components/ui/table/table-cell.svelte:19 2 (min-w-0) ledger-stacks cells become grid items of the row's phone grid and hold text; add max-phone:min-w-0`
- `defensive: apps/dashboard/src/lib/components/ui/table/table-cell.svelte:35 2 (min-w-0) matrix-stacks cells become grid items of the row's phone grid and hold text; add max-phone:min-w-0`
- `defensive: apps/dashboard/src/lib/components/ui/table/table-cell.svelte:38 2 (min-w-0) matrix-stacks-under cells become grid items of the row's phone grid and hold text; add max-phone:min-w-0`
- `defensive: apps/dashboard/src/lib/components/ui/table/table.svelte:7 6 (nested scroller) the sideways scroller sits inside the page's scrollers and chains its overscroll (a trackpad or touch swipe past its end scrolls or navigates the page); add overscroll-x-contain to the container slot`
- `defensive: apps/dashboard/src/lib/components/ui/table/table.svelte:13 9 (var fallback) --cell-gap is defined by the consumer, outside the kit; border-spacing-(--cell-gap) → border-spacing-(--cell-gap,0px)`
