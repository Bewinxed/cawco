## Tools for phase 2 (in `scripts/probe-kit/`)

- `snapshot-triage.ts`: every difference between two style-snapshot roots, grouped by `<property> · <before> → <after>`, with its count, where it lands and the files behind it. `--ground=<base>` keeps only what also differs base → after, to the same value (the hybrid filter). `--files=<attribution.json>` names each element's file; a kit part is named with the nearest file outside the kit that drew it. Without `--files`, it falls back to the element's or nearest ancestor's `data-slot`, marked `(by slot)`. The hybrid recipe and its exact commands are in its header.
- `specs/snapshot-attribution.ts` (`run.ts snapshot-attribution --surfaces=… --out=…`): each element, keyed as the snapshot keys it, with its `__svelte_meta` file and the components above it. It reloads each page on the dev server, waits until the count of elements carrying meta under the root is non-zero and has held for 1 s, re-runs the state's act, and waits again on its root. The dev server builds a page's modules on first request, so the walk's own load is the server's markup, with no meta and no router.
