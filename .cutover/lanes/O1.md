## Mechanism notes (judgement calls, for integration's compare)

- **The autosize twin** (motion/autosize.svelte.ts) is a shallow `cloneNode()` of MentionField's field, and `cssText` replaces its inline style. So a custom property set by `style:` on the field does not reach the twin. Composer's field box (`[data-slot="composer-field"]`, the twin's parent) therefore sets every length the twin measures with: `--field-size`, `--field-pad`, `--field-max-h`, and MentionField's chip sizes `--mention-chip-pad-end`, `--mention-chip-size`, `--mention-chip-leading`. MentionField sets the same three on its own field, so it stands alone (the dev finder).
- **Splitting the `font` shorthand.** MentionField's field (`type-body` + 16px + 1.25 became `font-body font-normal text-(length:--editor-fs) leading-ui`) and the tip (`type-meta`) now inherit the sub-properties the shorthand used to reset. body's `font: var(--type-body)` leaves them at the same initial values. The tip's handle (`font: var(--type-code)`) is `font-(family-name:--font-mono) text-size-code font-normal leading-code`, not `type-code`: `type-code`, and the base `.font-mono` rule, set `font-variant-ligatures: none` where the shorthand reset it to normal. Composer's command label (`font-family: var(--font-mono)`) uses `font-(family-name:--font-mono)` for the same reason.
- **Shadows.** `shadow-overlay` (Latest), `shadow-(--qchip-ring)` (RecallWheel's inset hairline) and `data-recalling:`/`data-grown:shadow-none` (Composer's pill) compute as Tailwind's five-layer `box-shadow`, with four transparent zero shadows in front. The map prescribes this; it looks the same, but the computed string differs.
- `border: 0` on Composer's field became `border-0`, so the computed border-style is solid (from preflight) where it was none, at width 0.
- `no-scrollbar` on MentionField's field also hides `::-webkit-scrollbar` (and sets `-ms-overflow-style`). The source had `scrollbar-width: none` alone there. Composer's field already had both.
- `.dock:has(.perch) .prompts` became `data-perched` on the dock (the perch is rendered exactly when the `perch` snippet is given) plus `group-data-perched/dock:pb-(--perch-rise)`. `group-has-*` is barred.
- `.asking .field > .editor` and `.asking .more` match an `.asking` dock (askRaised) or an `.asking` pill (askOpen), which are independent. The utilities carry both `group-data-asking/dock:` and `group-data-asking/cin:`, and the residuals use a bare `[data-asking]` ancestor.
- `.composer > :global(*) { pointer-events: auto }` is now `pointer-events-auto` on each of the composer's own children, plus a foreign-dom rule for AttachmentChips' root. As `[&>*]:pointer-events-auto` it would have outranked the canvas slot's own `pointer-events-none` by Tailwind's order. Nothing inserts other children into the column; canvas-room only reads its box.
- The progress slot's `inset-block-end: var(--shelf-rise, 0px)` keeps its fallback through `style:--progress-foot="var(--shelf-rise, 0px)"`, because `bottom-(--shelf-rise)` unset would compute to auto.
- RecallWheel's `perspective-origin: 50% 100%` became `perspective-origin-bottom`, and `transform-origin: 50% 100%` became `origin-bottom` (same computed value).
- Elements given a `data-slot` only so a residual can select them (no collisions in apps/dashboard/src): Composer's `prompts`, `tray-slot`, `progress-slot`, `perch`, `flight`, `flight-text`, `hint`; MentionField's `tip`.
- **LiveRow's face** keeps `style={face.rail}`, a string `railNow()` builds holding only `--rail-gap` and `--rail-head`. Splitting it into two `style:` directives needs that function to return the two values, which is a script change the lane rules forbid. The site carries `/* eslint-disable-line shadcn/no-inline-styles -- railNow's string: --rail-gap and --rail-head only */` at LiveRow.svelte:232 for integration to resolve.
- Row's `.continues` custom properties became `style:--rail-head` / `style:--rail-gap` under the same condition. Inline beats the `(0,2,0)` rules in Subagent and InlineTranscript that reset them on nested rows, as the `(0,3,0)` class rule did.
- Svelte's `style:` directives on MentionField's spread field go through `set_attributes` → `set_style`: `cssText` is written once, before the attachments run, and afterwards only the changed keys update. So autosize's inline `height` is never clobbered (svelte 5.57.1 `elements/style.js`, `attributes.js` `attribute_effect`).
