# Lane O4: the Tailwind cutover

Invariant: a class is a style, a state is an attribute, a hook is `data-slot`. Every file in the list is done (13 of 13); three of them keep a declared contract part as the foundation had it (`deferred-file:`, below).

Method notes that hold for every file:
- Tailwind's utilities sit in `@layer utilities`; a component's `<style>` is unlayered and beats every layered rule. So every residual was checked against the utilities on the same element (a residual that sets a property also set by a utility wins regardless of specificity), and every unlayered rule from another file that lands on these elements was checked for a flip (it now beats the utilities where it used to lose by specificity). Where a flip would follow, the declaration stayed unlayered as a residual and its note says which rule it outranks.
- Utility order was read, not assumed: a scratch script compiles candidate lists with the dashboard's own Tailwind 4.3.3 (`@tailwindcss/node`, theme.css + variants.css) and prints the generated rules in stylesheet order. Found by it: `hover:` sorts before `data-*:`/`active-*:`; `motion-safe:` sorts after `data-*:`; `dur-*` sets only `transition-duration`, so a later `transition-[…]` under another variant resets the duration unless `dur-*` is restated under that variant; `dur-*` takes theme keys only (a duration in a custom property is core `duration-(--x)`); `scale-(--x)`/`translate-*` write the `scale`/`translate` properties, not `transform`.
- `transition: none` under reduced motion is written as the base transition under `motion-safe:` plus `motion-reduce:transition-none`, so reduce computes the shorthand's longhands (property none, 0s, ease) and no-preference the base transition.
- A transform an element owns stays `transform` (`transform-(--x)` on a custom property holding the same function list), never Tailwind's `translate`/`scale` properties: the decks' inline `style.transform` writes, the intro animations and the `transition: transform` rules all act on `transform`.
- Custom properties a rule sets by state or medium stay in a residual: a `style:` one would outrank the media queries and the hosts' selectors that change them.
