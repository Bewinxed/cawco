## Mechanism notes (judgement calls)
- Home: the `page`/`rail` prop picks class arrays (`variant === "page" && …`), not data variants: no `home-variant-page:` variant exists and the prop is an input, not a run-time state.
- Rings / Relay / NeedsCaw / UpdateCard use named groups (`group/rings`, `group/relay`, `group/face`, `group/fold`, `group/disclosure`, `group/strip`, `group/row`) so an ancestor's own `group` (Shell has a `data-instant`) can never match.
- Rings' reserved arc: `.stale .arc` outranked `.arc.reserved.off` by source order; kept with `data-off:group-data-stale/rings:opacity-(--account-stale-opacity)`.
- Transforms that a transition names stay on `transform` (`transform-(--x)` with the function in a custom property: WeekMark, Rings, NeedsCaw's squash, NeedsCard's peek press, UpdateCard's chevron), because `scale-*`/`rotate-*` write the `scale`/`rotate` properties and the `transform` transitions would not run.
- CawFloat: the popover's and sheet's own rules go through the kit's `class` (+ a `style` custom property); the sheet's `::before` stays a pseudo residual on a new `data-caw-float-sheet` attribute (the kit sheet already owns its `data-slot`).
- UsageMeter: the sheet's overrides (`:global(.usage-sheet) …`) became the `limits(sheet)` snippet's own `sheet` argument; `usage-sheet`/`usage-pop` classes are gone.
- UpdateCard: `filter: blur()` → `blur-(--fold-blur)` / `filter-none` (the computed `filter` is the same single function).
- `transition: none` → `transition-none` sets `transition-property: none` (the shorthand also zeroed the duration); identical in effect.
