### New

- A project opens on Caw. Describe the work in your own words on New project and Caw drafts its board with you: stages, their look and who does each, all editable before Set up. Each project has one conversation with Caw, a full session with slash commands, skills and mentions
- Decisions: a project's decision pages are listed in one place, grouped Needs you, Sent and Decided. A page asks one question per card, each option shown live with what it gets and what it costs and one recommended. Picks reach the agent by themselves a few seconds after you stop
- Who decides routes each kind of choice to a member: you, Caw, the advisor, common practice, the agent that asked, or an agent you add. Each member has a card with its settings, its picture and a record of what it decided
- Component canvases: an agent shows a component as the real thing, every story drawn live in each hover, focus and pressed state, with an inspector for props, dials, a map of its states and a timeline for motion. They run on the project's own Vite, Astro or Nuxt dev server
- Tasks link by what they wait on (another task, a decision card, a pin, a pull request, a CI run, a session) and start once it settles. A task can have subtasks run by one coordinator, and its sheet shows what it produced, report first, with Try again
- Tasks stay in step with GitHub Issues, GitHub Projects or Linear: title, description, labels, stage and comments are one record on both sides. Connections cover GitHub, GitLab and Gitea/Forgejo, and work can land as a pull request on any of them
- gate.md declares a project's landing checks in any language or toolchain, and work lands only once they pass. It can also list the files Caw may edit himself
- Each project has its own browser for its agents, with sign-ins that last. Take it over for a sign-in or a captcha from a desk or a phone, with phone layout, touch and keyboard, and relay a passkey QR code to your phone. A stream relay in Settings › Browsers reaches it away from home
- Jump finds anything on every machine: sessions, tasks, routines, artifacts, commits, files and the moment something was said in a conversation. Agents search the same index, and passwords and keys in results are hidden
- Files collects a session's artifacts and attachments in one place, as thumbnails or a list. Comment and Draw work over PDFs, images and text files
- Agents draw blocks in a reply: tables, diagrams, charts, pictures, video, audio, slideshows and live pages. A block can be kept as an artifact
- Recent replaces Working and Finished in the sidebar, grouped by day, project, area or machine. Transcripts started in Claude Code outside the dashboard show there, and typing into one resumes it with the account, model and mode it ran with
- Project memory keeps facts as dated lines with their sources, and briefs carry only the lines that matter. Keys and passwords are cut before anything is stored
- Delegate types name the account, skills and MCP servers their sessions start with, and which types they may start. Delegates can run on a machine itself, outside a repository, and a delegate's outputs folder is kept in the project's assets
- Add a machine over SSH with its username and password, used once and never kept, or by a command. Require paired devices in Configure › Devices lets only paired devices and admitted machines reach the hub
- The hub answers as cawco.local on its network, and over HTTPS at its tailnet name on Tailscale. Every machine serves the dashboard at http://localhost:3455
- generate_image makes images through ChatGPT, Gemini through the Antigravity CLI, or a Gemini API key, picked in Configure › Models
- Containers a session starts stop when it ends. Named ones are kept; the rest are removed
- Each update copies the hub's database first and puts it back if the update rolls back. Claude Code is kept at its newest release on every machine without stopping a running session
- Delete project removes a project for good, optionally with its files. Forgotten projects lists what was forgotten, to bring back or delete

### Improved

- Switching tabs, two panes, streaming replies and long transcripts all do far less work. A stored session opens at its newest turns and loads older ones as you scroll up, and an idle page uses under half the CPU it did
- The dashboard loads much faster on a cold start and over a slow link: fewer startup files, compressed responses, smaller fonts, and half the download size
- Claude sessions run the Claude Code already installed on each machine, so the download is about half the size. A machine without it says so, with the install command
- At an account's limit a session moves whole to an account with room, the same organization first, and a long one continues from a summary. Accounts ahead of their week are picked last, and an account can be named per project or delegate type
- A message that can't reach the hub waits and goes once the connection is back, even after a reload, instead of failing
- Agents ask questions with their own ask tool and keep working while they wait. Each question says whether it blocks work, and survives restarts
- A new build no longer reloads an open tab under you: a toast offers Update now or Update when idle
- Delegate workspaces share one package store for bun, pnpm and Yarn, take a few MB instead of a full copy, and clean themselves up once nothing in them is unique
- Builds and checks wait for a free slot and run at low priority, so your own apps stay responsive while delegates build
- Comments on a page, preview or canvas reach the agent by themselves, and its replies stay in the pin's thread
- Errors from the hub show its own sentence, and a machine that is away is named
- The dashboard has one port everywhere, 3455. Bookmarks to :3000 need updating once
- No GitHub, GitLab or Gitea token reaches a workspace's commands; every push and post goes through the hub
- Code in transcripts and diffs is coloured in Go, Rust, SQL and about thirty more languages, up from seven
- The look is quieter and more consistent: Nunito throughout, bare icons, lighter dividers, one set of motion curves, and title bars in the Liquid Glass style
- Workflows are gone. Multi-step work runs as a session that hands its steps to delegates

### Fixed

- A session keeps its effort, mode and instructions through a crash, restart, account move or continue
- An update no longer rolls itself back on a busy machine, and no longer drops messages sent while it installs
- A machine that goes away no longer reads "reconnecting" forever, and machines rejoin within seconds when the hub comes back
- A hub stuck for two minutes restarts itself and says what it was doing
- A hub restart no longer loses work it was finishing, landing steps or waiting messages
- Old sessions stay asleep instead of being woken by notices
- In Safari on a phone, the permission card for a long command no longer freezes the page
- Many smaller fixes across decision pages, comments, canvases, the sidebar and the iOS app
